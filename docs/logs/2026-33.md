## Decisions

Week one. The repo got its name, its license, four ADRs, and a full audit of the PRD it was
supposed to execute. Every decision below is the owner's; ADRs record them.

- **Repo naming resolved.** Working title `overturn` → **`repeal`** (repo dir `rePeal`).
  Three names were live in the tree simultaneously — `overturn`, `mimir`, `repeal` — which
  the review caught as drift across the PRD, package path, and README.
- **License:** **Apache-2.0** for code. Data is not redistributed (PRD §4) — see ADR-004 for
  the gold-set release policy that follows from those terms.
- **D1 — Execution model:** no Anthropic API client module, no budget cap. All LLM stages run
  as Claude Code agent/skill workflows under the owner's Max plan (`claude-opus-5` for
  judgment-heavy surfaces, `claude-haiku-4-5` for bulk extraction); versioned JSONL/parquet
  artifacts carrying prompt hashes are the reproducibility contract; v1.1 runtime inference
  uses local models behind a LiteLLM-compatible interface. Also settled: development uses
  agent teams *within* a phase (the PRD's "sequential phases" governs phase order and the DoD
  review boundaries, not intra-phase parallelism), and the commit format is
  `action : description` per `CLAUDE.md`, superseding the PRD's "conventional commits".
  → `docs/adr/ADR-002-execution-model.md`
- **D2 — UI stack:** React/Vite frontend on the owner's design system ("claude design zip",
  supplied when the UI phase begins) + FastAPI backend. **Streamlit dropped.** Consequence:
  UI work cannot start before the zip is delivered. → `docs/adr/ADR-003-ui-stack.md`
- **D3 — Gold-set methodology:** keep 250 extraction gold cases; annotate via a multi-agent
  Claude Code workflow (N independent annotators with differing prompts → disagreement-driven
  adjudicator pass) plus an owner human spot-check tier of n ≥ 25. Circularity stated plainly
  (same model family annotates and is evaluated → agreement stats are inter-agent
  consistency, not independent ground truth). Release policy: ReferenceIDs + annotations +
  join script only, never `Findings` text.
  → `docs/adr/ADR-004-gold-set-methodology.md`
- **D4 — Scope:** a **walking-skeleton Phase 1.5** is inserted after Phase 1 — thin slice of
  ~100-case extraction → minimal DuckDB → logreg → single-page demo, end to end before any
  layer is built properly. **Phase 7 (text2SQL) is explicitly cuttable to v1.1.** Tracked in
  `TODO.md`; no separate ADR — this is scope sequencing within the PRD, not a stack deviation.
- **ADR-001 committed verbatim** from PRD §5 as the PRD instructs, plus an amendment closing
  the precedent channel: when retrieved precedents feed the Phase 5 few-shot predictor, each
  precedent is (scrubbed case card + `Determination`) only, the pool is restricted to cases
  decided before the query case's year, and the query case is self-excluded.

## Dead ends

- **The `llm_client.py` gateway.** The PRD's single-client module with content-hash caching,
  retries, token/cost JSONL, and a hard budget cap is a genuinely good design — for a project
  that pays per token. Under a Max subscription it is an elaborate guard around a constraint
  that does not exist, and the cost-telemetry half of it would have logged zeros forever.
  Abandoned before a line was written; the reproducibility job it was doing moved to
  artifact + prompt-hash logging (ADR-002). Worth recording because the *instinct* to build it
  was right and the premise was wrong — the tell was that PRD §12's cost risk row and §7's
  budget cap both traced back to a single assumption nobody had rechecked.
- **Streamlit for v1.** Kept on the board through the whole review on the PRD's "v1 speed
  over polish" argument. It only fell once the design zip made a real frontend cheap — the
  speed advantage *was* the entire case for it, so when that evaporated there was nothing
  left to weigh (ADR-003). Cost of the delay: Phase 2's annotation UI had to be re-specified
  as a CLI.
- **Uniform human adjudication of all 250 gold cases.** The PRD default. Rejected once
  multi-agent annotation became free: spending the owner's scarcest resource uniformly across
  cases where N independent annotators already agree is the wrong allocation. The redesign
  spends it on disagreement instead (ADR-004) — but it bought a real liability, the
  circularity limitation, which is now disclosed rather than solved.
